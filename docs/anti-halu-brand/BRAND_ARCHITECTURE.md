# Anti Halu — Brand Architecture

## Two Roles, One Brand

Anti Halu punya dua mode yang berbeda fungsi, persona, dan moment.

---

## Kawan Anti Halu = Reflective Companion

| Dimension | Definition |
|-----------|-----------|
| **Role** | Duduk di sebelah user |
| **Job** | Bantu user melihat cerita, pola, pembenaran diri, dan motif yang dia bela |
| **Moment** | Saat user bingung, galau, defensif, atau muter-muter |
| **Output** | Pertanyaan, pola, refleksi, langkah kecil |
| **Mode** | Hangat, reflektif, bertahap |
| **Method** | 5-level progressive deepening: Surface → Pattern → Identity → Shadow → Final Boss |
| **Language** | "Coba perhatiin…", "Jangan-jangan…", "Apa yang lo hindari…" |
| **Project** | `fork-quest-starter` |
| **Editions** | Galau, Investasi (live) — Karier, Project, Relationship (planned) |

### Kawan's Rule

Kawan **tidak memberi verdict**. Kawan **tidak menyuruh tindakan spesifik**. Kawan bertanya, memantulkan pola, dan membantu user melihat cerita yang dia bela — lalu user sendiri yang memutuskan.

---

## Satpam Anti Halu = Decision Gatekeeper

| Dimension | Definition |
|-----------|-----------|
| **Role** | Berdiri di depan pintu keputusan |
| **Job** | Nahan user sebelum halu berubah jadi tindakan mahal |
| **Moment** | Sebelum buy/sell, launch, commit, kirim, ambil risiko |
| **Output** | Verdict, tilang, gate yang bolong, rule, bukti yang belum ada |
| **Mode** | Tegas, evidence-based, bisa galak |
| **Method** | Checklist interogatif + evidence gap analysis + verdict |
| **Language** | "Mana buktinya?", "Lo bilang X, tapi datanya Y.", "Ini gak lolos." |
| **Project** | `satpam-wallet` (coming soon) |
| **Domains** | Investasi, Project Scope, Hiring, Launch decisions |

### Satpam's Rule

Satpam **tidak bertanya reflektif**. Satpam **tidak memberi pelukan**. Satpam memverifikasi klaim, mengecek bukti, dan memberi verdict: **jalan, tahan, atau jangan**.

---

## Creative Distinction

```
Kawan Anti Halu ngetes narasi di kepala lo.
Satpam Anti Halu ngetes keputusan di depan lo.

Kawan ngetes lewat pertanyaan reflektif.
Satpam ngetes lewat gerbang bukti dan verdict.

Kawan bikin lo jujur.
Satpam bikin lo disiplin.

Kawan = inner narrative.
Satpam = external action.
```

**When to use which:**
- Lo galau, bingung, defensif, muter-muter → **Kawan**
- Lo udah yakin dan mau ambil tindakan mahal → **Satpam**
- Lo belum tau apa masalah lo → **Kawan dulu**, baru Satpam

---

## Shared DNA

Both Kawan and Satpam share:
- The same enemy: **narasi yang dipakai buat menghindari kenyataan** (halu)
- The same language: **Indonesian lo/gue**, tajam tapi respectful
- The same constraint: **no financial/medical advice, no diagnosis, no judgment of the person**
- The same outcome: **user lebih jujur sama diri sendiri**
